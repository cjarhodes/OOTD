# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository's Security tab, not in a public issue.

Particularly welcome: anything that lets someone sign in as another person (`/api/auth/*`, `src/server/accounts.ts`, `src/server/session.ts`), read or change another account's wardrobe or photos (`/api/wardrobe`, `/api/photos`), or use AI tagging beyond its allowance (`/api/tag`).
